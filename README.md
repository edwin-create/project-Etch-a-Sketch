Etch-a-Sketch Project - Overview

This Etch-a-Sketch project is a browser-based drawing application built using HTML, CSS, and JavaScript. It mimicks the classic Etch-a-Sketch toy with modern interactivity.

Features

Dynamic Grid: Users can adjust the grid size (up to 100x100) for varying levels of detail.
Clear Canvas: Reset the grid to start fresh with a single button click.
Responsive Design: The interface adapts to different screen sizes for a seamless experience.

Technologies

HTML: Structures the interface.
CSS: Styles the grid and controls, with a focus on responsiveness.
JavaScript: Handles grid generation, user inputs, and dynamic color application.
